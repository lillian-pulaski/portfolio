A full-stack Django application for running digital signage on Raspberry Pi displays. Administrators upload and schedule content of every kind, from images to announcements to live data, and the system rotates it through an automated slideshow.

  • Role-based authentication separating admin and editor permissions
  • Automated slideshow rotation with configurable timing and display control
  • HDMI-CEC integration so the Pi powers the TV on and off on schedule
  • Python scrapers pulling live weather and date/time onto the screen
  • JSON API integration for outside sources, including campus announcements
  • Validated image uploads managed through the database
  • Support for custom HTML slides when a layout needs something specific
  • Django
  • Python
  • Raspberry Pi
  • HDMI-CEC
  • HTML / CSS

A full revamp of an existing site for a Broome County nonprofit, handled solo from the brand work through to launch. The organization had no documented visual identity, so the project started by extracting one from what was already in use and developing a palette around it to carry that identity across the site. The rebuild focused on the things that actually keep people from finding help: navigation organized around the services offered, a layout that holds up on a phone, and clearer type and contrast throughout. Ticketing for the organization's fundraiser runs through the same site, and staff can update content without needing a developer.
